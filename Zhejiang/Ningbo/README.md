# 宁波市 Ningbo

## 数据 Data

### 轨道交通

识别方式：1E文件，线路和站点，每条线有长短两种写法

数据文件：metro-tu.csv

### 公交

识别方式：线路代码为4位数字，前3位为基础路号（不足3位左补0），第4位为支线号（0为主线），如 7030 即 703 路，7034 为其支线 703-4

数据文件：bus-tu.csv
