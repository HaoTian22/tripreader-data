# 佛山市 Foshan

## 数据 Data

### 轨道交通

TU识别方式：1E文件，线路和站点

目前有两种写法

`00430019000000`（广州写法）或`32430029588009`（佛山写法）

均为第3-4位位置表示线路，第7-8位表示站点  
佛山写法9-12位（5880）表示地区，后面09未知；佛山巴士写法相同

故此处删除开头的00

数据文件：metro-tu.csv

### 公交

识别方式：1E文件线路和站点头四位数

市区线为3a3b，a是线路10位，b是线路1位，会出现撞码情况

大沥为93ab，ab为沥+线路号10位和1位
